# 2026-09-13 Daily Challenge 提示语与实际行为对齐

## 背景

首页 Daily Challenge 卡片的提示语 `BEAT IT → YOUR NAME JOINS THE HALL ▼` 是从设计交接稿逐字
抄来的。交接稿的完整设想是：完成当日目标后标签旁显示 ✔，并把三字母街机名缩写写进当天的 Hall
条目。2026-09-05 首页 spec 第 3 条已决定**不做**完成判定、✔ 与写入 Hall（需要在 8 个游戏里各自
埋点上报，超出首页范围），但这行硬编码在视图里的提示语没有随功能一起砍掉，也没有测试锁住它。
结果是页面向玩家承诺了一个不存在的功能。

## 决定

- 提示语改为 `NEW CABINET EVERY DAY → BRAGGING RIGHTS ONLY`。
  - 描述的是现有行为：每天按日期哈希换一个游戏，`ACCEPT ▸` 只是跳转过去。
  - 「bragging rights only」明说没有奖励、没有上榜，语气仍是街机口吻。
  - 去掉末尾的 `▼`：它原本指向下方 Hall of Fame，暗示两者有关联，而 Hall 只是各游戏最高分
    的前三名，与挑战无关。
- **不补功能。** 完成判定要动 8 个 `logic.ts` 的导出与存储层，且当前 Hall 是分数榜，塞名字进去
  得重新定义整块卡片。这是另一个 spec 的事，不在本次范围。
- 与设计稿的偏离**有意为之**：artboard 上仍是旧句子，后人别照稿「改回去」。

## 涉及文件

- `tests/hub-view.test.ts` — 新增断言：提示语不再承诺上榜。

  （Snake 38），日期固定为 2026-09-12 以保持画面中的挑战游戏不变。
